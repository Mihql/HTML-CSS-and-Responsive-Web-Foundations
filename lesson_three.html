Creating an HTML file To demonstrate an HTML boilerplate, we first need an HTML file to work with. Create a new folder on your computer and name it html-boilerplate. Within that folder create a new file and name it index.html. We should always name the HTML file that will contain the homepage of our website index.html. This is because web servers will by default look for an index.html page when users land on our websites - and not having one wil cause big problems.
